# 1. 模块概述

M11 练习模式模块提供单人练习与 AI 对抗入口，包含 Count Up 计分练习、随机结镖练习、99 Darts 练习、Cricket MPR 挑战、AI 对战练习五种入口。练习模式是用户提升飞镖技术的重要场景，不计入胜负与排名；练习数据为 B 级——仅本地留存并同步 M9 练习记录页，不计入个人综合统计。

## 1.1 模块职责

- • 练习模式选择页（Count Up / 随机结镖 / 99 Darts / Cricket MPR 挑战 / AI 对战练习，共 5 张卡片，整卡点击进入）
- • Count Up 练习（8 轮 24 镖，累计最高分，追求高分）
- • Random Checkout 练习（随机结镖目标，练习结镖）
- • 99 Darts 练习（选定 1 个打分区，33 轮 × 3 镖共 99 镖专注度训练，★V1.00 补写）
- • Cricket MPR 挑战（10 轮 × 3 镖标记率挑战，15-20 与 Bull 计标记，★V1.00 以代码为准）
- • AI 对战练习入口（跳转对局设置页并预选「真人 vs AI」，不含独立难度表，★V1.00 补回）

## 10.2 输入与规则边界

- MVP 只支持已实现的逐镖键盘输入（dart_by_dart）和镖靶图点击输入（board_tap）；两者均生成有顺序的 List<Dart>。

- 极速结镖模拟比赛已进入收尾阶段，默认视为已经完成开分；inMode 固定 STRAIGHT_IN 或传递等价的已开分状态，不执行 Double In 第一镖检查。
- 默认 outMode=DOUBLE_OUT、标准 Bull。用户实际镖序直接交 M2 逐镖 X01 规则裁定；归零时检查实际最后一镖，超分、留下1分或非法 Out 均判 Bust。
- 第1或第2镖合法归零时立即 Checkout，不接受后续飞镖，也不补 MISS。
## 10.3 目标生成与难度

- M11 负责随机选题，M2 负责提供统一的 Checkout 路线事实。候选目标必须由 getCheckoutRecommendation() 或其统一路线数据源返回至少一条1-3镖具体合法路线。
- M11 与 UI 不维护第二份不可结镖分数表；不得硬编码排除1-19。Double Out 下1不可结镖，但2=D1、3=S1+D1等低分目标合法。
- 入门：存在1镖或常用2镖路线；进阶：最少2镖或低复杂度3镖路线；挑战：最少3镖并优先高分、易Bust路线；混合：按配置权重抽取。
- 固定10题会话内尽量不重复目标；自由练习允许跨较长序列后重复。
## 10.4 计时与状态

- 每题显示3、2、1倒计时；倒计时结束时揭示目标并启动 throwElapsedMs。
- 用户投完或提前结镖后点击主按钮「完成投掷（冻结成绩）」，冻结 throwElapsedMs；随后开始 inputElapsedMs，录入确认后停止。主成绩只使用 throwElapsedMs。主按钮 UI 原文随阶段切换 —— 投掷态「完成投掷（冻结成绩）」；录入态「确认结果」、未录镖时「确认结果（未录镖 = 未完成）」；禁用态「倒计时中…」/「本题已结算」/「训练已暂停」。
- 进入后台时暂停本题并禁止本题刷新个人最佳；返回后只允许重新开始本题或退出。进程被杀时不恢复正在计时的题目。
- 状态至少包括：倒计时、计时中、已停止待录入、录入中、校验中、Checkout、Bust、未完成、跳过、异常中止。

## 10.8 数据与统计红线

## 10.9 验收标准

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
