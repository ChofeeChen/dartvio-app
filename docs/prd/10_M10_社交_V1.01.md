# 1. 模块概述

M10 社交系统模块负责用户社交关系管理，包括好友列表、好友资料、好友申请通知、添加好友（搜索/推荐）、好友邀请比赛等功能。社交系统是增强用户粘性和促进在线对战的重要模块。

## 1.1 模块职责

- • 好友列表展示（在线状态/PPR/最近活跃）
- • 好友资料页（基本信息/统计数据/比赛记录）
- • 好友申请管理（发送/接收/同意/拒绝）
- • 添加好友（搜索用户ID/昵称/推荐好友）
- • 好友邀请比赛（从好友列表直接邀请）
- • 在线状态显示（在线/游戏中/离线）
- • 删除好友/拉黑（P1）
## 1.2 模块边界

| 属于M10 | 不属于M10 |
| --- | --- |
| 好友关系管理 | 用户账户注册登录（M1） |
| 好友申请和通知 | 比赛邀请的房间创建（M6） |
| 添加好友搜索 | 实时聊天（P2，不做） |
| 好友在线状态 | 用户统计数据计算（M9） |
| 好友资料页UI | 个人资料编辑（M1） |
| 好友邀请比赛 | 动态/社区（不做） |

## 1.3 依赖关系

| 依赖模块 | 依赖内容 | 接口 |
| --- | --- | --- |
| M1 基础设施 | 用户信息/本地存储/推送通知 | User.getProfile(), Notification.push() |
| M9 统计成就 | 好友统计数据/比赛历史 | Stats.getUserStats(), Stats.getMatchHistory() |
| M6 比赛大厅 | 邀请好友创建房间 | Room.createWithFriend(friendId) |
| M5 实时同步 | 好友在线状态实时更新 | Realtime.on("presence_update") |

## 1.4 被依赖关系

| 被依赖模块 | 使用方式 |
| --- | --- |
| 首页/个人中心 | 好友入口/好友申请红点提示 |
| M6 比赛大厅 | 房间等候页邀请好友 |
| M7 对局UI | 对手是好友时显示好友标识 |

#### ③ 交互流程图

进入好友列表页
 → 调用 getFriendList(userId) 获取好友列表
 → 按 presence 分组：在线（online）→ 游戏中（in_match）→ 离线（offline）
 → 在线/游戏中按最后活跃时间倒序，离线按最后活跃时间倒序
 → 注册 Realtime.on('presence_update') 监听好友在线状态实时变化

用户点击"添加好友" (#btn-add-friend)
 → Navigation.push(AddFriendViewController)

用户点击"申请" (#btn-requests)
 → Navigation.push(FriendRequestViewController)
 → 清除红点徽章

用户点击在线好友的"邀请" (#btn-invite)
 → 调用 inviteFriendToMatch(friendId)
 → 创建私密房间（默认X01 501/双倍出/20回合上限/休闲单局，可在房间修改）
 → 好友收到推送通知"玩家A邀请你一起玩飞镖"
 → 自己跳转到房间等候页
 → 好友点击通知 → 加入房间

用户点击游戏中好友的"观战" (#btn-watch)
 → 检查好友所在房间是否允许观战
 → 允许 → Navigation.push(SpectatorViewController(roomId))
 → 不允许 → Toast"好友的比赛不允许观战"

用户点击好友行或"资料" (#btn-profile)
 → Navigation.push(FriendProfileViewController(friendId))

好友在线状态实时更新
 → 收到 presence_update 事件 → 更新对应好友的状态图标和分组
 → 在线→游戏中：好友行从"在线"组移到"游戏中"组
 → 游戏中→在线：从"游戏中"移到"在线"
 → 在线→离线：从"在线"移到"离线"组，显示最后活跃时间

左滑操作（P1）
 → 左滑好友行 → 显示"删除"和"备注"按钮
 → 删除 → 确认弹窗 → 调用 deleteFriend(friendId) → 从列表移除
 → 备注 → 弹出输入框 → 调用 updateFriendRemark → 列表更新备注名
