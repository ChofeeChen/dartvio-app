统一入口 DartVioTheme 基于 Material 3 ColorScheme；页面和可复用组件仅消费 MaterialTheme.colorScheme 或 DartVioTheme 的语义扩展。原始调色板、状态色及明暗映射集中于主题层，替换色板不得逐页修改。

映射约定：Material 3 已有角色由 ColorScheme 提供，文字/边框等语义别名集中映射至相应 on*、outline 等角色；warning 与 success 等补充角色由 DartVio 扩展 Tokens 集中提供，并随主题统一注入。业务代码不得另建零散状态色常量。最终 API 字段适配实际依赖版本，不在文档中锁定库版本。

# 1. 模块概述

M1 基础设施模块负责App的基础架构：首页（功能聚合与数据概览）、个人中心、应用设置、隐私设置、设计系统规范、存储与日志。v1.2首页按"核心动作最短路径+入口分层高频前置+硬件状态全局可见+数据概览驱动留存"四原则重设计为A-F六区。

# 2. 首页设计原则（v1.2）

- 1. 核心动作最短路径：本地比赛入口作为主CTA占据最醒目位置，一键直达对局设置。
- 2. 入口分层高频前置：按使用频率分三级——核心行动区（2个入口：本地比赛主CTA整行 + 练习模式整行次级卡片）→功能宫格（4个图标入口）→底部Tab全局导航。在线对战由底部"大厅"Tab独立承载，不在首页重复设入口。
- 3. 硬件状态全局可见：设备连接状态在首页顶部常驻显示，未连接引导配网，已连接展示信号与电量。
- 4. 数据概览驱动留存：首屏展示PPR、胜率、总场次三项核心数据，点击直达统计详情。

隐私设置页（v1.2新增，对应首页入口规划文档§3.3）：

约战邀请开关：
 → 默认关闭（隐私优先）

 → 开启后：用户出现在"仅邀请"预约房间的可选邀请列表中（公开玩家分组）
 → 关闭后：立即从公开玩家池移除；已发出未处理邀请仍有效至24小时失效

公开信息分级（开启约战邀请后可设置）：
 → Level 1：仅昵称（最低限度公开）
 → Level 2（推荐）：昵称+头像+等级
 → Level 3：昵称+头像+等级+PPR+胜率
 → 邀请者在邀请列表中看到的信息范围=被邀请者设置的公开级别
 → Level 1用户在公开玩家排序中排在最后（无PPR数据无法按水平匹配）

仅好友可邀请（独立开关）：
 → 与"约战邀请"开关独立
 → 即使开启了约战邀请，如果同时开启"仅好友可邀请"，则不会出现在公开玩家邀请列表中
 → 仅M10好友可发起邀请

免打扰时段：
 → 用户可设置时段（如23:00-8:00）
 → 此时段内不发送邀请推送通知
 → 邀请本身仍保留，App内可正常查看
 → 时段结束后如有未处理邀请可补发一次提醒

屏蔽玩家（P2）：
 → 用户可屏蔽特定玩家，被屏蔽者无法发送邀请
 → 屏蔽列表在隐私设置中管理
