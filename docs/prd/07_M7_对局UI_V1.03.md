# 1. 模块概述

M7 对局UI模块负责比赛相关所有页面：玩法选择、比赛设置、对局计分、局结果与整场结果。
★V1.00 定位澄清（本版最重要的一条）：App V0.1 阶段一的 UI 已实现且构建通过，其结构与本文档 §2 起的 P7.x 设计目标态存在系统性差异 —— 文档才是落后的那一份。因此本版约定：§1.1「已实现界面基线（as-built）」是开发的唯一依据；§2 的页面定义、§3 的 v1.7 跳转、§4 的 A7.1-A7.37 一律视为「设计目标态」，仅在其被 §1.1 标注为「已实现」时才对 V1.00 生效。
★V1.00 版本号修正：原文件名版本为 v1.9，但文档内最新变更记录为 v1.10，二者不一致；本次修订按批次约定一并归零为 V1.00。

# 1.1 ★V1.00 已实现界面基线（as-built）

本节描述 App V0.1 阶段一「实际存在」的界面，来源为代码 ui/ 与 ui/navigation/DartVioNavHost.kt。凡本节未列出的页面 / 控件，即为未实现，不得在 V1.00 的 UI 中出现入口或占位。
A. 实际导航图（Compose Navigation，app/src/main/java/com/dartvio/app/ui/navigation/DartVioNavHost.kt）
　• 路由常量 Routes：home / x01_setup / x01_detail / setup/{matchType} / game（共 5 条，无其他路由）
　• home →（X01 卡片）→ x01_setup
　• home →（Cricket 卡片）→ setup/{matchType}
　• x01_setup →（详细设置）→ x01_detail →（保存 / 返回）→ 回填 x01_setup（MatchSession.detailConfig）
　• x01_setup →（开始比赛）→ game；setup/{matchType} →（开始比赛）→ game （均写 MatchSession.pendingConfig / pendingPlayers）
　• game → 对局结束 → 在 GameScreen 内联渲染结果页（无独立结果页路由）
　• game → 退出 → 回退到 home

　⚠️已知偏差 2：game 路由依赖 MatchSession 内存缓存，缓存为空时 GameScreen 不渲染任何内容（无兜底）。
