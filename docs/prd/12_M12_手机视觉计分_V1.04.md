# 1. 模块概述

## 1.1 模块职责

M12 手机视觉计分模块负责：在用户把手机固定于靶盘侧前方（一次性标定）后，通过手机自带摄像头自动识别每一支镖的落点与得分，产出与手动录入完全一致的 Dart(number, multiplier) 序列，作为继 M3 手动录入、M4 AI 回合、M8 外置硬件之后的**第四种输入来源**。
　• 定位：**半自动辅助计分**（识别候选 + 用户确认/修正），不是免确认的全自动计分。
　• 零外置电子硬件：不需要主控盒 / 专用摄像头，仅需手机 + 支架（+ 推荐补光）。
　• 端侧闭环：视频帧不出设备、不落盘，仅产出结构化「落点 + 置信度」。
　• 规则无关：M12 只产出 Dart 列表，判定与计分全部复用 M2 规则引擎，规则引擎零改动。

## 1.2 模块边界

包含（In Scope）：

- 机位与标定要求（角度 / 距离 / 靶面占比 / 一次性标定流程 / BOM）
采集与权限（CameraX、CAMERA 权限、端侧隐私、能力门槛 gate）
落点识别管线（触发 → 静帧 → 靶面单应 → 镖尖定位 → 几何映射 → 置信度）
置信度与交互（≥90% 确认 / <90% 回落 M3、低置信度提示开关、撤销）
数据契约（Dart + confidence + source=phone_vision，下游复用 M2 / M9）
验收指标与分期路线
不包含（Out of Scope，明确排除，且已给出排除理由）：

- 双目 / 多目深度：Android CameraX 仅支持双摄并发且不保证多摄同时输出，手机侧不成立；需多目的方案归入 M8 外置硬件。
飞行轨迹检测：飞镖约 20 m/s，轨迹级检测需 ≥500–2000 fps，手机不可行；本篇只做「镖入靶静止后」的单帧检测。
云侧推理：隐私与延迟代价 + 预算约束（纯软件 ≤¥300）下排除，MVP 锁定端侧。
外置硬件设备管理（发现 / 配网 / 绑定 / OTA）：属 M8。
规则判定与计分：属 M2。

# 3. 机位与标定要求

## 3.1 机位几何要求

- 入射角：偏轴 15–25°（按标准靶计分区直径 340 mm、外双倍环直径 340 mm）。正对 0° 会因投影重叠难以区分同分区多镖；侧向 45° 会让靶面椭圆化（短轴 ×cos45° ≈ 0.707，分辨率掉约 30%）并放大镖尖视差。
距离：1.0–2.0 m。该区间对应 1080p 下靶面（整板 451 mm）投影约 666–333 px、单像素约 0.68–1.35 mm，双倍 / 三倍环（宽 8 mm）约 11.8–5.9 px。
靶面占比：≥15% 画面宽（低于此值提示用户调整机位）。
高度与俯角：机位略高于靶盘中心、俯角 ≤15°，避免投手身体遮挡检测窗口。
稳定性：必须使用支架固定，禁止手持（手持会破坏标定与定位精度）。
★关键量化前提：标准靶双倍 / 三倍环宽仅 8 mm，径向容差 ±4 mm；考虑分区角度在靶心附近收窄，落点定位 p95 误差目标为 **< 3 mm**（靶面平面）。
## 3.2 一次性标定流程（★成败关键）

- 流程：进入标定页 → 取景覆盖整个靶盘 → 自动探测靶面结构（靶心 / 双倍-三倍环 / 20 分区）→ 以不少于 4 对非共线对应点拟合单应矩阵 H（推荐靶面环上多点最小二乘）→ 显示残差，超阈值时提示重标。
人工 4 点为兜底（首次或自动失败时）：**明确标注其残差可达 3–10 mm，等于吃掉全部误差预算，仅作临时方案**。
标定结果与机位绑定本地存储；机位被移动、镜头更换、分辨率变更时须重新标定。
标定完成后进入对局页；标定失效时回落 M3，不阻塞对局。

# 5. 识别管线（目标态）

## 5.1 处理流程

- ① 触发：用户点按「识别该镖」，或帧差自动触发（P1，检测「投掷前 / 后」变化区域为新镖）。
② 捕获：取镖入靶静止后的一帧高快门图像。
③ 靶面定位：复用标定所得单应矩阵 H（必要时逐帧精修）。
④ 镖尖定位：检测镖身与靶面接触端的像素坐标（该点为真实落点）。
⑤ 几何映射：像素 → 靶面平面坐标 (x, y) → 极坐标 (r, θ)。
⑥ 分区判定：按 r 判定倍数（靶心 / 三倍 / 单倍 / 双倍 / 脱靶），按 θ 判定数字（1..20）。
⑦ 置信度：由定位残差、靶面清晰度、模型得分等加权合成 [0,1]。
## 5.2 落点映射规则（与 M2 / Dart 模型一致）

| 判定条件（靶面极坐标 r） | 产出 Dart | 说明 |
| --- | --- | --- |
| r ≤ 6.35 mm | Dart(25, 2) | 内靶心 / Inner Bull，50 分 |
| 6.35 < r ≤ 15.9 mm | Dart(25, 1) | 外靶心 / Outer Bull，25 分 |
| 99 < r ≤ 107 mm | Dart(n, 3) | 三倍环（环宽 8 mm） |
| 162 < r ≤ 170 mm | Dart(n, 2) | 双倍环（环宽 8 mm） |
| 其他 r ≤ 170 mm | Dart(n, 1) | 单倍区 |
| r > 170 mm | Dart.MISS | 脱靶（number=0） |

## 5.3 置信度定义

confidence = 加权合成（定位残差 / 靶面清晰度 / 模型置信），取值 [0,1]。阈值口径与 M8 完全一致：≥90% 视为高置信度，<90% 视为低置信度。M12 不自定义阈值，避免同一产品内出现两套识别质量标准。

# 6. 置信度与交互（★复用 M8 口径）

- ≥90%（高置信度）：显示识别结果（分区 + 分数 + 置信度），提供「确认」/「修正」按钮，确认后提交该镖分数并继续识别下一镖。
<90%（低置信度）：黄色警告框 + 提示用户确认；**修正入口直接回落 M3 手动面板并预填候选值**（M12 特有：比 M8 多一步预填，因端侧精度低于硬件）。
「低置信度提示」开关：切换低置信度时是否提示用户确认（与 M8 同名同义）。
撤销：与 M3 / M7 现有撤销机制一致（逐镖回退）。
★禁止：低置信度时静默计分；一回合内切换输入来源。
# 7. 回合流程与异常降级

## 7.1 回合边界（MVP 不做自动切分）

- MVP：回合边界仍由现有「3 镖完成」交互与用户操作决定；每支镖独立识别、独立确认。
拔镖 / 空靶检测（P1）：作为增强项，可开关，默认关闭；检测到拔镖且靶面清空时提示进入下一回合。**不作为 MVP 依赖**（这是流程闭环中最易低估的一环，故首期明确不做）。
## 7.2 异常与降级

| 异常 | 处理 |
| --- | --- |
| 光照不足 / 靶面占比不足 | 提示用户调整；可自动提高置信度阈值或一键回落 M3 |
| 标定失效（残差超阈值） | 提示重新标定；其间回落 M3 |
| 遮挡 / 识别超时（>3 s） | 丢弃本次识别结果，回落 M3 |
| 连续 N 次低置信度 | 建议关闭 M12 或检查机位 / 光照 |
| 能力不满足（系统 / 内存 / 相机） | 禁用 M12 入口并说明原因，对局功能不受影响 |

# 11. 技术预研（PoC）计划

本章为 M12 进入 MVP 开发前的**前置验证计划**。M12 全篇为目标态设计，本节同理——它不描述已实现能力，而是定义「在花开发预算之前，如何用最小成本证伪 / 证实前提」。

## 11.1 目的、范围与原则

- 目的：验证 M12 成立的三个前置假设（H1–H3），给出 GO / NO-GO 结论。
范围：只验证「靶面标定 → 镖尖定位 → 端侧性能」链路；不含完整 UI、不含在线对战、不含拔镖自动切分。
原则：**先验证几何，再训练模型**。几何不成立时，模型精度再高也无意义（§5.2 落点映射依赖标定）。
原则：**逐节点止损**（kill criteria 见 11.4），不为「已经投入的沉没成本」继续加码。
## 11.2 前置假设（H1–H3）

| 编号 | 假设内容 | 不成立时的后果 |
| --- | --- | --- |
| H1 | 自动靶面标定可做到反投影残差 < 1.5 mm，且一次性标定成功率 ≥ 90% | 精度上限被锁死（8 mm 环宽吃掉全部误差预算），须退回人工 4 点标定并重估体验 |
| H2 | 镖尖像素定位换算到靶面后，p95 误差 < 3 mm（理想机位 / 光照条件） | A12.7 的 label ≥ 95% 不可达，须退化为「仅报候选 + 强制确认」或放弃 |
| H3 | 单帧端到端延迟 ≤ 1.5 s，且中端机连续 30 分钟不明显降频 / 过热 | 体验不成立，须降模型规模 / 降推理频率 / 依赖 NPU（受算子覆盖限制） |

## 11.3 阶段路线（P0–P4）

| 阶段 | 时长 | 内容 | 通过判据 | 交付物 |
| --- | --- | --- | --- | --- |
| P0 几何验证（零训练） | 1–2 天 | 纯经典 CV + 人工 4 点标定；打印标定板测反投影残差 | 残差 < 1.5 mm | 残差测量报告 + 标定工具脚本 |
| P1 自动标定 | 3–5 天 | 自动探测靶面结构（靶心 / 双倍-三倍环 / 20 分区）→ 拟合单应 + 残差校验 + 漂移提示 | 自动标定残差 < 1.5 mm 且一次成功率 ≥ 90% | 标定模块原型 |
| P2 镖尖模型 v0 | 1–2 周 | 合成数据 + 受控自采集自标注；热力图关键点；PC 端评测像素误差 | 换算靶面 p95 < 3 mm | 模型文件 + 评测报告 |
| P3 端侧移植 | 1 周 | LiteRT CompiledModel + int8 量化；测延迟 / 功耗 / 发热 | 单帧 ≤ 1.5 s；30 min 不明显降频 | 端侧 Demo |
| P4 闭环验证 | 1 周 | App 内「拍照 → 出候选 Dart → 用户确认」；跑 200 镖统计 | 确认后准确率 ≥ 95%；误检 < 1% | 闭环 Demo + 准确率报告 |

说明：P0 可与 P1 并行启动；**P0 + P1 是关键路径**——它们决定 M12 的数学前提是否成立，且几乎不消耗训练成本。

## 11.4 通过判据与止损（GO / NO-GO）

| 节点 | GO 判据 | NO-GO 处置 |
| --- | --- | --- |
| P0 出口 | 反投影残差 < 1.5 mm | 残差 ≥ 3 mm：停止预研，回到 §10 重新论证 |
| P1 出口 | 自动标定残差 < 1.5 mm 且成功率 ≥ 90% | 不可达：降级为「人工标定 + 明确告知用户」，重估体验与宣称口径 |
| P2 出口 | 靶面 p95 < 3 mm | 3–5 mm：保留方案但强制确认、下调精度宣称；> 5 mm：NO-GO |
| P3 出口 | ≤ 1.5 s 且不过热 | 不达标：降配（更小模型 / 降帧率）后重测；仍不达标则重估 |
| P4 出口 | 理想条件下确认后准确率 ≥ 95% | 不达标：重估取值区间，或退回 M8 硬件方案 |

★ 任一节点 NO-GO 均视为**有效结论**（止损即收益），不得以「再做一版试试」续期。

## 11.7 数据策略

- 合成 + 域随机化：把镖体素材合成到靶面图，随机光照 / 角度 / 模糊 / 遮挡 / 机型噪声 → 可产出数十万张，边际成本最低。
受控自采集 + 几何自标注：因机位与标定已知，可由「真实分值」反推镖尖像素坐标，**自动生成关键点标签**，人工成本近零。
少量人工精标：仅用于构建**测试集**。★ 不得用自标注数据做最终评测（同源偏差会使指标虚高）。
评测集必须跨维度覆盖：机型 × 靶盘品牌 × 光照 × 机位角度 × 左 / 右手，**每个维度单独出指标**，均值会掩盖失效场景。
## 11.8 离线回归测试基建（★性价比最高的投资）

- 录制覆盖各条件的固定视频集，作为不可变回归语料。
离线回放工具：算法 / 模型每次改动都跑一遍，输出定位误差分布、各维度准确率、延迟。
无此基建则模型迭代不可控——「改好了 A、改坏了 B」无法被发现。

# 12. 手点与视觉共用几何契约

M3 靶盘点选与 M12 手机视觉必须复用 BoardGeometry.dartAt() 及同一靶面毫米坐标系：原点为靶心、x 向右、y 向上。BoardLayout 只负责画布坐标与毫米坐标转换，不得复制或修改判分常量。相同毫米落点必须得到相同 Dart。

# 13. 视觉反馈主题语义与可访问表达

手机视觉计分的置信度和确认流程保持不变；本节统一页面反馈的主题实现。

- 低置信度使用 WarningContainer 与 OnWarningContainer，并同时显示警告图标、置信度数值和确认或修正文案，不以黄色作为唯一验收条件。
- 识别失败和不可用使用 Error 语义；确认候选使用 Primary；手动修正使用 Secondary 或 Outline；禁用使用 Disabled 语义。
- 叠加在相机画面上的文字与标记必须使用遮罩或对比容器，确保 Light、Dark 和不同靶面背景下可读。
- 控件与触控热区消费 Size、Spacing Token，布局使用 dp，字号使用 sp；主题变化不得改变 BoardGeometry 坐标或置信度阈值。
