## 用户拍板 + P0 PoC 脚本落地 ✅
- ★拍板结果：D1 先 PoC / D2 Supabase Edge Function / **D3 每镖一拍（非我推荐的一轮一拍）** / D4 修订为「静帧可上传」/ D5 Lite 起步。已写回评估文档 §12。
- ★**每镖一拍的三个后果**（已写入文档）：①必须做**多镖差分**——模型返回全部针尖，本地用「本轮已确认镖的靶面 mm 坐标」按 <15mm 剔除旧镖（**不让模型判断哪个是新的**）；剩 0 提示重拍、剩 ≥2 让用户点选 ②成本与等待 ×3（做成可配置，默认每镖一拍、可切一轮一拍）③现有 20 张素材**全是单镖图**，验证不了差分 ⇒ 需补拍「同轮连续 3 镖」≥15 张。
- 交付 `M12_PoC/tools/poc_doubao_vision.py`（离线，不碰 App）：ROI 裁切→长边 1024 压缩≤200KB→调模型取**像素坐标**→映回原图→`evaluate_pixel` 判分→比对 `truth.label`；`--dry-run` 无密钥自检。复用 `DartVision` 的 Homography/evaluate_pixel（与 App 内 `BoardGeometry.dartAt` 同源）。
- dry-run 自检（20 样本，iPhone15Pro 3024×4032，标定残差 2.21mm）：链路自洽 20/20、误差 0.0mm。
- ★★**置信度口径问题（重要发现）**：按现口径 `置信=余量/(3×噪声)`、噪声=max(1.0,标定残差2.21)，**判分全对时也只有 7/20 ≥0.90** —— 余量 2–4mm（贴三倍/双倍，打得准的表现）只有 0.33–0.60 ⇒ 落地会让大量正确的镖强制回落手动。修正建议：噪声改用 **PoC 实测误差 P90**、分母 3σ→1.0–1.5σ；置信以**模型自报为主**，本地余量只在 `worst<0` 或 <1mm 时降级。不阻塞 P0，P1 前必须定。
- 素材事实：`data/sessions/20260913_p0_iphone/labels.json` 每条含 `truth.label/score`（人工真值）+ `tip_img` + `board_mm` + `H_img_to_board`；`calib.json` 有 H 与残差；`session.json` 记录机位（1200mm / yaw45 / pitch8 / indirect_led / UNICORN）。`datasets/*/keypoints.json` 另有关键点标注。
